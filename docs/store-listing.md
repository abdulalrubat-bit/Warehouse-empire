# Play Store listing copy

Current as of v25 (3.8). Paste the blocks below into Play Console → Main store
listing. **Keep the blank lines** — see the warning under "Full description".

---

## Title (30 char limit)

```
Warehouse Empire: Idle Tycoon
```

29 characters. Unchanged — it carries "idle" and "tycoon", which is what people
actually type into Play search, and there is no reason to spend the goodwill of
an existing title.

---

## Short description (80 char limit)

```
Run a logistics empire that keeps earning while you're away. Hire and automate.
```

79 characters.

The one it replaces was *"Build a logistics empire that runs while you're away.
Tap, hire, automate."* Tapping led the sentence, and tapping is the least
interesting thing in the game — its value is pegged at 5% of your idle rate, so
it never outgrows or falls behind what the site already earns. The line now
leads with the thing a player is actually buying.

**The version currently live has lost its line breaks.** Every heading is jammed
inline — "…without you. Automate everything Climb the equipment tiers…" — so the
whole thing renders as one unbroken wall of text. Paste the block below *with its
blank lines intact*; if your browser strips them again, type the returns back in
before saving.

It is also out of date: it names three manifests when there are five, "32+
achievements" when there are 44, and describes none of the top-down site view,
the four specialised sites, the Directorship, or the Network as a managed layer.

### What changed and why

- **Line breaks restored**, with headings on their own lines. This is the single
  biggest improvement and it is not a writing change at all.
- **Tapping no longer leads.** It is still in the game and still the first thing
  you do; it is no longer sold as the point.
- **The site view leads instead**, because it is the strongest thing the game has
  and the listing never mentioned it.
- **Counts corrected**: five manifests, 44 awards, twelve ranks.
- **The changeover, the four sites, the Directorship and the Network** are
  described, because all of them shipped after this copy was written.
- **"No internet required" softened to "plays fully without a connection."** The
  game does now send anonymous statistics, as the privacy policy sets out, so the
  stronger claim is no longer strictly true.
- **Keyword coverage kept**: idle, tycoon, logistics, warehouse, automate,
  offline, empire, manager. Play indexes this field.
